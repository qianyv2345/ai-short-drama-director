# 文本审核回归测试

这些是格式与检查器的合成测试素材，不是导演质量标杆，也不包含用户剧本。

环境：Python 3 和 PowerShell 7（`pwsh`），或 Windows PowerShell（`powershell.exe`）。

```powershell
python -m unittest discover -s tests -p 'test_audit_video_prompt.py' -v
```

如果运行时不在 PATH，通过 `PWSH` 环境变量指定完整可执行文件路径。没有 PowerShell 时测试会明确 skip，不能把 skip 当成审核通过。

覆盖画幅 × 生成段上限 × 格式的 8 种组合、旧元数据模板、比例冲突、竖屏显式多脸与横屏多人豁免、单段长度、时间粒度、时间轴空缺/重叠、逐镜六字段、对白原文、实体、删除镜号、旧前缀兼容等。

简版支持 `0-5秒：画面描述`。需要按原分镜编号审核删除结果时，写成 `0-5秒：镜头编号：17-01；画面描述`，否则 `ExpectedAbsentShotId` 会明确失败，不能用自动生成的解析编号假装完成镜号审核。

`OutputFormat` 默认 `Auto`，也可显式指定 `Compact` 或 `Detailed`。详细格式逐镜校验六字段，不会再强迫简版补六字段。Auto 同时兼容粗体镜号标题下直接写简洁正文的旧版格式；只要某镜包含六字段标记之一，就按详细格式检查该镜的完整六字段。

建议每个生成段声明一行 `画面比例：9:16` 或 `画面比例：16:9`。旧输出未声明会警告但保持兼容。脚本仅能检查显式人脸数量声明（`清晰人脸数量：2`）与画幅的部分冲突，不能证明自然语言构图符合单脸约束，也不能代替视频验收。没有必要为了审核而在每镜强加数量字段。
