# Shared Shot & Prompt Constraints (Single Source of Truth)

本文件集中定义分镜设计与 AI 视频／图片提示词共用的硬性约束，避免多文件口径漂移。

---

## 1. 时间轴粒度与时长估算

- **0.5 秒粒度**：所有镜头起止时间、单镜时长和音效时间码只能是 `0.5` 的倍数（如 `0`、`0.5`、`1`、`1.5`、`2`），禁止 `0.3`、`1.2` 等非半秒时间；时间显示省略多余 `.0`。
- **整数秒生成段**：每个生成段必须从 `0` 秒开始、在**整数秒**结束，首尾相接无空隙无重叠；段标题总时长必须与所有镜头时长之和一致（`15秒版 ≤ 15秒`，`30秒版 ≤ 30秒`）。
- **无对白镜头**：空镜、环境建立、普通反应、转场和无对白细节通常 **1.5–3 秒**（信息简单 1.5–2 秒，需看清细节 2.5–3 秒）；关键人物登场、重大情绪变化、复杂动作结果或异常变化可适当延长。
- **对白时长估算**：按 **每秒 5–6 个可朗读汉字**（通常可用 **5.5 字/秒** 初算，标点不计，语气停顿／气口／动作间隔另加），结果向上对齐到 `0.5` 秒倍数。严禁为压缩时长删改台词或压快到无法自然表演。
- **半秒凑整处理**：当分段内总和差 0.5 秒凑成整数秒时，优先微调无对白停留或动作尾部时长，不删改原对白。

## 2. 景别优先级与相邻镜头去重（含跨段）

- **默认优先级**：`特写 / 近景 / 中近景 > 中景 > 全景 / 大全景`。以人物表情、眼神、手部动作与关键道具推进叙事；中景、全景与大全景仅在新场景建立、必须交代空间／多人关系、完整身体动作、进出空间或用户明确要求时使用，交代完毕尽快回近景体系。
- **相邻镜头去重**：相邻两个镜头**禁止**以相近景别连续拍同一人物的脸（如 `近景→近景`、`特写→特写`、`特写→近景`、`近景→特写`）；仅微调角度、机位或小幅推拉仍视为重复。
  - **优先切法**：在两张同人面部镜之间切入有剧情依据的空镜、其他在场人物反应、双人／多人关系、关键道具，或该人物的手部／身体与环境互动；不得为去重凭空新增角色、道具或动作。
  - **必须连续拍同一人时**：使用明显跨度景别（如 `面部特写 → 中景动作` 或 `近景 → 全景完整动作`），并让后一镜承担新的动作或空间信息。
- **跨生成段同查**：以上一段最后实际可见画面的主体和景别，对照下一段第一幅实际可见画面（含段尾或段首内嵌切镜的实际收尾／起镜构图），同时接住动作进度、站位、视线与持物状态。

## 3. 长对白切镜与反应镜头衔接

- **触发条件**：在**允许设计或调整切镜**的范围内，连续对白预计 **超过 5 秒（5 秒整不触发）** 时，必须在保持原对白原文、顺序和声音连续的前提下，至少穿插一处其他在场人物反应、双人／多人画面，或有剧情依据的空镜／环境／关键道具细节。
- **锁定边界例外**：用户明确要求**一镜到底**，或**仅转写已确认分镜**时，保留已锁定镜头边界与原对白，在连续单镜内用视线、动作、停顿或经允许的运镜组织节奏；**不得把短对白机械切碎**。
- **时间码写法**：补充镜头必须**直接写入对应镜头的摄影机／运镜字段**，用 0.5 秒时间码写清起止与画面（如 `0-3秒：@甲近景；3-5.5秒：切@乙反应近景`），不得只在备注概括；已写明时间码的补充画面属于计划内切镜。没有其他实际入画角色时改用空镜／环境／道具细节，不得新增人物。
- **反应镜后接下一独立镜头的回切规则**：
  - 若下一独立镜头主体**仍是反应人物乙**：必须在当前长对白镜头的摄影机／运镜字段尾部先切回说话人甲，再进下一镜乙，即 **`甲说话 → 乙反应 → 甲说话 → 下一镜乙`**（禁止 `乙反应` 直接接 `下一镜乙`）。
  - 若下一独立镜头主体是**丙或其他非乙主体**：可直接 **`甲说话 → 乙反应 → 下一镜丙`**，不强制回切甲。
  - 回切保持原对白声音、文字和顺序连续，不重复台词、不凭空加动作。

## 4. 过肩镜头三要素与 180° 轴线

- **过肩完整句式**：无论普通分镜还是提示词、9:16 还是 16:9，凡过肩镜头必须在机位／摄影机／运镜字段写清三项关系：**从谁的左肩或右肩后方拍摄谁**。统一写成 `从@前景人物左肩后方拍@被摄人物` 或 `从@前景人物右肩后方拍@被摄人物`（普通分镜不加 `@`）。只写“过肩／肩后拍／拍对方”或漏任一人物／肩位均视为不完整。
- **肩位推导与构图**：肩位按当前站位、面朝和摄影机所在轴线侧推导，不套固定模板，且前景人物与被摄人物不得写反；肩部只占画面边缘并虚化，不得遮挡主体面部、手部动作或关键道具。
- **180° 轴线**：对话、对峙、打斗相邻正反打保持同一轴线侧与视线左右对应（A 在左看右，B 在右看左）；需要越轴时插入中性镜、正轴镜或展示可见运镜越轴过程（除非剧情明确制造混乱）。

## 5. 画幅执行规则（9:16 竖屏 vs 16:9 横屏）

### 9:16 竖屏
- **构图策略**：以正反打、干净单人中近景、近景、特写为主；背景只写剧情必需的时间、天气、空间锚点、光线与关键道具，减少无关陈设与复杂环境运动（不删必要空间关系或动作依据）。
- **人脸数量控制（严禁多脸畸变）**：
  - **非过肩的中景／中近景／近景／特写／大特写及其他非全景**：**只能出现 1 张清晰人脸**，不允许任何其他人脸（含模糊、局部露出、侧面、倒影、玻璃反光、屏幕或照片人脸）；其他人物只能完全出画，或只露不含脸部的肩背、手部。
  - **过肩镜头**：前景人物只许露肩部、后脑或背影，**不得露出可辨认的前景脸部**；主体保留 1 张清晰人脸。
  - **9:16 全景／大全景**：允许多人入画且人脸可清晰辨认，但身份、特征和位置必须稳定，严禁复制脸、重复脸、镜面／屏幕额外脸或凭空人脸。纯手部、道具和空镜可无人脸。
- **【表情与口型】统一规范**：
  - **有对白且人物露脸的 9:16 镜头**：必须写 `【表情与口型】`，依次写明眼神方向与焦点、眉眼／嘴角微表情、口型开合与节奏、停顿和身体反应（含起始→变化→结束状态），不用“表情自然／正常说话”等空话；若用户明确为**后期配音且要求不强制精确口型**，则侧重微表情与自然说话状态。
  - **无对白但人物露脸的 9:16 镜头**：写明眼神、微表情、呼吸／身体反应及嘴唇状态（如“嘴唇始终合拢”或“微张欲言又止”），避免无台词却强行编造说话口型。

### 16:9 横屏
- 按已确认分镜交代空间建立、横向调度与必要多人关系，可使用双人／多人镜头，不套用 9:16 单人与单脸限制，但仍须逐镜写清每个入画者的具体定位与连续性。

## 6. 独立定位、连续性核对与人物指向

- **观众视角槽位**：`中位`（画面中心）、`左一位／右一位`（紧邻中心）、`左二位／右二位`（更靠边缘），按观众看到的左右定义，不按角色自身左右手。
- **角与朝向分离**：每名实际入画人物须独立写明：`槽位 + 空间位置与前后层次 + 姿态 + 起始动作 + 身体与镜头夹角（正面／四分之三面向／侧面／四分之三背对／背面）+ 实际面朝／视线方向 + 关键造型／道具／左右手状态`。
- **缺失站位由 AI 导演推演**：剧本或分镜未明确站位时，根据场景结构、动作目的、视线、180° 轴线、景别、画面重心与前后连续性直接推演合理站位并写入具体结果；严禁写“按分镜锚点／站位未明确／由模型自行理解”。
- **只写本镜入画者**：画外发声、电话声、旁白、回忆声或仅被台词提及的人物不进本镜人物定位（但可标注其画外方向作视线／发声目标）；无人镜写清本镜无人物。
- **实名人物指向（提示词）**：提示词中用 `@实际姓名` 点明动作执行者、触发者、接收者、视线对象、被摄者和焦点归属（如 `@林默的右手`、`焦点落在@阿宁眼睛`、`听见画面右侧画外的@沈舟说话`），减少“她／对方”含混指代。
- **相邻防穿帮核对清单**（编写者在输出前校准完毕，跨段同样适用）：
  1. 槽位、前后层次、朝向、视线、180° 轴线；
  2. 动作起点、过程、接触／支撑点与落点；
  3. 道具持有者、位置及明确左右手；
  4. 服装、发型、污渍、伤势、面具等持续状态；
  5. 门窗开合、家具、镜面与背景结构；
  6. 时间、天气、主光源方向、色调与明暗。

## 7. 剧本实体差异审计与道具文字可读状态

- **实体差异审计**：制作分镜或 Prompt 前，先建立本范围实体清单（已命名人物、角色类别、画外／提及人物、场景地点、组织、道具、药品、武器、数字单位、缩写、专业术语、称谓、关键状态、旧项目／模板残留词），与剧本、最新分镜、本轮用户要求和最终输出逐项比对。
  - Prompt 出现剧本／最新分镜中不存在的新实体时，先标为待核对，不默认写成新角色／道具；疑似错别字或术语不一致时报告原文与疑似修正，不静默改写；用户本轮明确补充的实体可保留但与原剧本事实分开标记。交付前核实：**新增实体、缺失实体、疑似旧项目残留**。
- **道具可见文字状态**：涉及药瓶、标签、屏幕、手机、电脑、纸张、门牌、招牌、通知、界面等对象时，必须区分“剧情里知道是什么”和“画面里字能不能看清”。必须写明文字位置、出现时段与可见状态之一：**无可读文字 / 完整可读并逐字匹配原文 / 部分可读 / 模糊不可辨 / 仅保留磨损或图形纹理**。剧本若写明磨损或不清，严禁把道具名称自动渲染成清晰文字。

## 8. 光线分层、风格物理一致性与声音约束

- **全局与局部光线分层**：
  - **全局光线基线**（写在段首 `【场景】`）：连续场景共用的时段感、天气、主色调、整体明暗、主要环境光与轮廓光方向（连贯场景内保持一致；室内亦须写时间、天气及窗外入光影响；实在无依据时写 `时间：未明确，保持参考图时段；天气：未明确，保持参考图天气`）。
  - **镜头局部光线**（写在单镜 `光影` / `环境场与情绪光影`）：服务当前表演、道具或动作落点的局部主光、辅光、轮廓光、实用光与对比度，**不得无说明地翻转全局时间、主色调或主光源方向**。锁死全局与局部需求冲突时，明确“全局保持、局部调整”，勿把矛盾灯光平均混写。
- **风格词物理一致性**：将风格词拆检为 **拍摄设备／记录介质、光学特征、灯光方法、后期纹理、CG 渲染方式** 五类。真人实拍不得无解释混入 3D 模型／动画材质；数字摄影与胶片颗粒／胶片色彩并存时须区分拍摄来源与后期模拟质感。发现冲突先提示风险，**不静默删改用户固定风格词**。
- **声音与无音色标签**：
  - 环境音与动作拟音须源自可见动作、已知环境或剧本声音，写清出现时点（0.5 秒粒度）、远近、方向与强弱；**不凭空增加改变剧情的信息性声源**（如未入画车声、警报、人声），除非用户或剧本明确要求否则**不默认添加 BGM**。分贝值仅在有混音需要时选填。
  - **禁音色标签**：用户已有固定音色时，禁止推断或输出“音色、声线、音高、年龄音、中音／高音、语言、口音、声音质感、声音模型”或 `[音:……]` `[语言:……]` 标签；仅在剧本有依据时保留“低声、失声惊呼、哭喊”等表演状态。
