# Style Profiles

本文件只保存可选视觉风格，不提供默认风格。

## 调用规则

- 用户必须在当前任务中明确指定风格类别，或明确要求调用本文件中的某个风格档案，才能把风格词写入提示词。
- 用户未指定风格时，不自动加入任何真人、仿真人、3D动漫、国漫CG、UE5或其他风格前缀。
- 不跨项目、集数或版本沿用上一次的风格。
- 用户在当前任务中提供了新风格提示词时，以新提示词为最高版本，逐字保留。
- 风格只改变美学介质与渲染表达，不改变剧情、人物身份、动作、对白、镜头顺序和空间逻辑。
- 真人、仿真人、3D动漫和国漫CG的角色介质标记必须与当前风格一致，不得混写。

## 风格词物理一致性检查

调用风格档案时，将风格词拆分为拍摄设备／记录介质、光学特征、灯光方法、后期纹理和CG渲染方式分别检查。真人实拍不得无解释地混入3D模型、动画介质或CG材质；数字摄影设备、胶片颗粒和胶片色彩可以组合，但要区分拍摄来源与后期模拟质感。发现物理介质可能冲突时先提示风险；用户当前任务提供的固定风格词仍逐字保留，不静默删改。

## 已暂存：真人电影写实（视觉）

仅在用户当前任务明确要求“真人写实”“真人电影感”，或明确指定调用本档案时使用：

```text
真人写实风格，电影真实感画面，戏剧性侧光，高反光比，电影级调色，8k超清细节，运镜丝滑，人物动作流畅，环境衔接流畅。
```

声音与对白策略不属于视觉风格本体。只有当前任务没有单独指定声音方案时，才可按需补充“有音效、无音乐、自然对白、符合语境的停顿和气口”等声音要求；用户明确要求BGM、音色或其他声音方案时，以当前任务要求为准。

如果用户只说“仿真人”，先结合当前项目已有参考图和用户本轮措辞判断介质，不把“真人写实”档案自动等同于所有仿真人或半写实3D项目。无法确定时只使用用户明确给出的风格词。

【前置锁定】整段视频默认无文字无字幕；剧本明确要求的剧情内文字除外。严格执行已确认镜头顺序、时间轴和动作因果，不临时增加镜头、角色或剧情。动作有完整动力链，人物、轴线与空间连续。

本次更新统一的是仓库自带模板。若当前用户提供的固定原文仍包含“可增加镜头”或“时间仅参考”，先指出与锁定时间轴冲突并确认取舍，不静默改写用户原文。

## 其他风格

除上述已暂存档案外，其他具体风格仍在用户当前任务中给出或确认后再按当前任务调用；未经用户要求不要把新风格永久写入本文件。
