# 导演设计核心

本文件是导演决策、切镜动机、表演和修改传播的唯一规则来源。不是让每次输出增加长篇分析；默认在制作规划中完成，仅在用户要求或需要确认时展示简短导演卡。镜头必须首先服务剧情，不以“顶级”“大师级”、焦距数量、镜头数量或提示词长度替代质量。

## 1. 先锁事实，再设计

读取用户指定集数及必要上下文，保护原对白逐字内容、先后顺序、人物身份、剧情结果和当前批准的修改。用户只要单集时不自动输出整部，不自动加3秒钩子、道具表或新剧情。改编差异先核对是否来自用户要求，不拿初版剧本覆盖确认版本。

独立无集数的测试片段可用0作为临时集号并在正文外注明，不冒充正式集数；正式指定集数时使用真实集数。剧本未给时间天气且没有参考图时不虚构“依参考图”，只写不改变剧情的最低必要环境条件；涉及日夜等会改变剧情的歧义才询问。

任务参数独立记录：画幅（9:16 / 16:9）、单段上限（15 / 30秒）、输出格式（简版 / 六字段）、明确选定的视觉风格。未给时长、比例且没有当前任务的有效选择时，只问缺少项；不因竖屏默认15秒，不因横屏默认30秒，不因详细格式自动加CG。

## 2. 每场导演卡 → 节拍 → 镜头

用户直接要提示词时，以下步骤在内部完成，不先输出分镜或要求确认。已有确认分镜且只需转换时，只做必要检查，不重复创作。

先用一行一句完成六项：
- 观看立场：观众此刻最应关注谁，知道或不知道什么？
- 冲突目标：谁想得到什么，谁或什么在阻止？没有冲突的过渡场不要强行制造冲突。
- 起止关系：主动权、距离、信任或风险如何改变？
- 转折触发：原文哪句台词或哪个动作使局面改变？
- 信息顺序：先露什么、暂藏什么、何时兑现？不得隐去剧情必须交代的信息。
- 核心视觉策略：本场最多选一个主策略，如隔玻璃的不可接近、听者反应、空间压迫或由混乱到稳定；无必要可不用特殊手法。

按刺激→反应→选择/行动划分戏剧节拍，不按每句话机械拆镜。每镜在规划中标记主要功能：信息、情绪、动作结果、关系变化或必要空间建立。删除该镜如果没有损失，先尝试合并；不能为了通过审核虚构功能。

## 3. 切镜和节奏

超过5秒是检查画面是否仍有有效变化的提醒，不是强制切镜。持续变化的表演可以停留；听者可以在同一镜中听完再说话。反应人物与下一镜主体相同，优先合并为持续镜头，不强制切回说话人。明确说话人、画内/画外状态，原对白及顺序不变。

同主体近景切特写等组合不是禁区，但必须确实改变信息、视点或心理重量，并避免无依据的跳切；若只是重复，合并而不是硬插空镜。插道具、手部或环境必须有新的状态、线索、情绪或动作结果。不要在不同段反复插同一未变化的包装袋、监测曲线等填充物。

不用“每两秒切一次”或“长镜头更高级”替代判断。轻松、发现异常、爆发、余波可以有不同密度；不能强迫所有戏都有同一曲线。停留应有可见的表演任务，不是空等。时间不够先调整分段，不压缩必要情绪落点或原对白。

## 4. 可拍的表演和摄影

先判断人物想表达、隐藏、争取或回避什么，再选1—2个可读行为：刺激到达→注意力变化→尝试控制→控制结果。不是每镜都瞪眼、握拳、倒吸气；无依据不添加哭泣、攻击等改变人物行为的结果。

焦距、机位、景深、推拉、变焦只在影响透视、空间关系、注意力或情绪时使用。把效果写清，数值不是专业程度的证明。不得用1.5秒群像全景同时要求每个人都有清楚微表情并完成复杂变焦；全景承担群体/空间变化，关键认知由具体人物承接。

## 5. 动作与对白时间预算

先列动作依赖：必须串行的动作分别估时，可并行的动作有物理依据。吃完→咽下→下椅→走到墙→打勾不能全部写成“同步”。核对路程、起身、转身、接触/松手、重心和道具交接。不要仅凭字数估计动作时长。

用户明确的单镜最低时长、口播上限、声音方案、服装与关键道具设定记录为本请求参数，不能提升为其他项目默认。用户要求每镜≥1.5秒时，包括插入画面在内均核对；用户要求不高于5—6字/秒时，按不超过6字/秒的上限检查并预留真实停顿，语义需更慢时放慢，不能理解为每句必须达到6字/秒。

反应画面可覆盖连续对白；动作可和说话并行，但吞咽、急促奔跑、换手等必须符合动作与发声条件，不额外重复计算并行时间。

对白用自然试读估时，停顿、呼吸和情绪转折单独留量；不得删改、加速原台词来凑段长。视频未实际生成时标明预算是估算。超载按顺序处理：删去无叙事价值的新增动作→减少无关运镜→延长到上限以内→按完整动作/自然句界拆段。仍不可能时报告冲突，不伪造可执行时间轴。

保持原有0.5秒粒度、整数段长及15/30秒上限。片段上限不是必须填满的目标。声音可以跨画面，但不允许同一角色不可能的口型/吞咽并行。

## 6. 连续性与修改传播

制作规划保存每段首尾状态：人物身份、画面位置/朝向/视线、支撑姿态、左右手接触对象及部位、关键道具归属、服装伤势、空间轴线、时间光线。只保留该场必要字段，不用输出巨型模板。

局部修改步骤：
1. 锁定最新参考图、用户批准状态和版本来源；有矛盾先确认，不自行认定左右手。
2. 找到受影响镜头及邻接生成段。改变S03初始抓握，必须回查S02末帧；改变交接，还需检查其后所有持有状态。
3. 更新受影响的分镜、人物区块、时间轴、连续性限制和示例，不只修当前段说明。
4. 比较前段末状态和后段初状态，任何变化必须有可见过程或明确时间跳跃。
5. 重新审核被修改段及前后段，列出修改范围和未验证项。没有原始参考图时不要声称已核对图像。

## 7. 规划与生成正文分层

导演卡、镜头功能和状态表供设计与审核；生成正文只写可执行事实。每个独立生成段完整包含当前场景、实际入画角色和初始状态、唯一时间轴及声音；每镜写必要变化和特有风险，避免重复所有全局禁令。只画外发声的人不列为入画角色。

简版维持简洁时间轴；六字段保留字段名及顺序，但一个事实只归属一个主要字段，其他字段补充不同信息。不把时间轴整段复制到表情/口型字段。无对白镜头不强加对白气口要求，无人物镜头不强加人脸要求。独立提取片段时重新补齐所需上下文，不使用“同上”。

## 8. 验收

文本审核和导演评价分开：脚本检查格式/时间/可解析规则，不能认证导演水平或成片。人工检查原对白、信息顺序、行为因果、动作预算、横竖屏可读性和段间状态。

用同一段剧本和相同参数做旧/新版比较，观察表演、信息清晰度、节奏和生成稳定性；不以模型自评分、镜头变少或文案变长作为成功证据。没有视频只能报告文本层改进。标杆示例见 examples/directing_examples.md；不自动套用其中情节或固定镜头长度。
