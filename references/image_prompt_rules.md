# Image Prompt Rules（首帧／分镜／场景静态生图）

当用户明确要求生成 **首帧Prompt、首帧生图、分镜生图Prompt、场景生图Prompt、图片提示词** 时读取本文件。制作普通分镜或未明确要求时，禁止默认输出生图 Prompt。

---

## 1. 核心原则

1. **静态单帧思维**：图片模型只生成某一瞬间的定格画面，**严禁写入**连续时间轴（`0-2秒`）、多阶段连续动作、镜头切换、持续运镜变化（如“先推再摇”）、对白文本或音效时间码。
2. **锚定分镜起始或定格瞬间**：
   - **首帧生图 Prompt**：严格锁定对应分镜的**第 0 秒起始定格状态**（主体槽位、姿态、表情起点、道具及左右手状态、起点构图），以便图生视频模型直接承接动作展开。
   - **分镜生图 Prompt**：定格该镜头最具戏剧张力或最能代表该镜信息的瞬间。
   - **场景生图 Prompt**：交代空间结构、门窗家具与全局光线基线，默认无人入画（除非用户明确带人物参考站位）。
3. **风格按需与参考图优先**：遵守 `SKILL.md` 与 `references/shared_constraints.md` 的风格按需规则及物理一致性检查；已有角色参考图／三视图时不重复长篇描写外貌。

---

## 2. 人物姓名与画面约束

- **已命名人物加 `@`**：静态生图提示词中出现的已命名人物前加 `@`（如 `@林默（参考图）`），普通角色类别词不加 `@`。
- **9:16 竖屏静态人脸规则**：与视频规则一致，非全景非过肩只允许 1 张清晰人脸，严防倒影／玻璃／屏幕多脸；过肩只露前景虚化肩背无前景脸。
- **可见文字状态**：画面出现屏幕、纸张、药瓶、招牌、门牌时，必须明确写清“无可读文字 / 完整可读「原文」 / 模糊不可辨 / 仅保留磨损纹理”，避免乱码字。
- **首句无文字声明**：若当前图片模型容易误加字幕／水印，可保留 `画面无文字无字幕无水印（剧情明确要求的可读文字除外）。`

---

## 3. 输出模板

### A. 首帧／分镜生图 Prompt 模板

```text
### [镜头编号] 首帧生图Prompt｜[9:16竖屏或16:9横屏]

画面无文字无字幕无水印；剧情明确要求的画面内文字除外。

[仅用户明确指定时才加入的风格词]

【场景与光影】明确时段、天气、空间结构、关键陈设位置、全局主色调、主要光源方向与局部轮廓光／辅光关系。
【景别与机位】静态景别（如近景／特写／中近景）、机位高度与角度（如平视／右前方30°／从@前景人物右肩后方拍@被摄人物）、焦点落点与景深（如浅景深虚化背景）。
【画面构图与人物定格】逐一写明实际入画角色的参考图标记、画面槽位、空间位置、前后层次、定格姿态、身体与镜头夹角、面朝与视线方向、道具及左右手握持状态、起始微表情（如紧闭双唇／眼神微凝）。本镜无人时写“画面无人物”。
【连续性与细节限制】保持角色参考图外貌与服装一致，道具文字状态（如“无可读文字”），不新增人物与多余肢体，画面边缘构图不裁切关键面部或手部。
```

### B. 场景生图 Prompt 模板

```text
### [场景名称] 场景生图Prompt｜[9:16竖屏或16:9横屏]

画面无文字无字幕无水印；场景明确要求的招牌或标识文字除外。

[仅用户明确指定时才加入的风格词]

【空间与陈设】内景／外景、建筑与空间结构、门窗朝向、核心家具与关键道具精确摆位、材质质感与空气状态。
【时间天气与光影】明确时段与天气、窗外入光与室内自然光关系、主光方向、色温冷暖、明暗对比与氛围。
【机位与透视】广角／全景／中景建立视角、机位高度、地平线或透视方向，保持无人物空场（或按用户要求放置参考站位）。
```
