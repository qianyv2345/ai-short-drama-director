# Storyboard Rules

用于指导制作专业影视分镜。所有共用的硬性规则（0.5 秒时间粒度、景别优先级与相邻／跨段去重、长对白 >5 秒切镜与回切、过肩三要素、180° 轴线、实体审计与光线分层）见 `references/shared_constraints.md`，本文件不再重复抄录。

---

## 1. 分镜核心原则与优先级

分镜不是逐句拆剧本，而是把文字剧情转化为**可拍摄、可观看、可剪辑、可表演、AI 可稳定执行**的视觉镜头。

- **人物姓名格式**：普通分镜使用正常人名，**不加 `@`**；仅在转换为视频／图片提示词时加 `@`。原对白内部逐字保留，不加 `@`。
- **设计优先级**：`1. 观众此刻该知道什么 → 2. 该看谁 → 3. 核心情绪 → 4. 动作是否需完整展示 → 5. 是否需要切镜 → 6. AI 能否稳定执行`。不要先想炫酷运镜。

---

## 2. 景别使用细则

默认遵循 `特写 / 近景 / 中近景 > 中景 > 全景 / 大全景`（去重细则见 `shared_constraints.md`）：

- **大全景**：建立宏大环境（城市、战场、山谷等）或表现人物与巨大空间关系；仅作必要建立，避免连续使用。
- **全景**：展示完整身体动作、交代人物站位、多人走位、人物进出空间。
- **中景**：上半身动作、必须同时看清两人的较大幅度互动；**能用中近景表达时，不默认用中景**。
- **中近景**：情绪对话、重点反应、较强人物存在感；短剧常用主景别。
- **近景**：强调情绪、重要台词、人物反应；短剧优先使用。
- **特写**：眼神、微表情、手部动作、屏幕、关键物体与信息（仅在剧情真正需要观众看清时才切特写）。
- **大特写**：谨慎使用，仅用于眼睛、极端情绪或关键微小细节，避免连续大量使用。

## 3. 机位与运镜设计

### 机位选择
- **平视**（默认自然，适合对话与日常）、**低机位／仰拍**（压迫感、强势、英雄、威胁感；勿默认给主角全套仰拍）、**高机位**（弱势、无助、环境压迫、空间关系）、**俯拍**（位置关系、大空间、特殊节奏）。

### 运镜时机与戏剧目的
先确定一镜要交代什么变化：人物仅靠表演已能说清变化时，**固定机位**往往更高级；需要运动时只选**一个核心摄影机动作**（可附一次轻微焦点转移），写清**触发时机、起始机位、方向、速度、幅度、主体构图与停点**，禁止只写“高级运镜／电影级运镜”。

| 这一镜要交代的变化 | 可选拍法 |
| --- | --- |
| 对峙中一方压近 | 用已有肩背或门框加强前后层次；确需推近时，在对方逼问或前倾的节点起推，停在受压人物的反应上 |
| 两人渐渐疏远 | 固定构图给人物朝向留出空位；需要交代实际距离时，用中景或全景展示人物分开 |
| 关键物件或信息揭示 | 保持机位，焦点从手或前景转到画面中原本就有的物件；需借遮挡揭示时，用短横移交代空间 |

### 常见运镜适用场景
- **固定**：对话、强表演、紧张等待、稳定构图。
- **推镜 / 拉镜**：情绪渐强、发现重要信息（推）；揭示环境、孤独感、情绪收束（拉）。
- **横移 / 视差滑轨**：跟随人物或展示空间；优先利用场景中**原本就有的**门框、屏风、桌案、肩部、帘幕作前景产生视差，绝不凭空加遮挡物。
- **前景遮挡揭示**：从前景物体后方缓慢横移露出主体（人物登场、危险暴露、观察者视角）。
- **跟拍**：行走、奔跑、进入空间；临近落点减速停定。
- **环绕**：仅用于重要人物登场、局势逆转或情绪顶点，控制 **10°–30° 小幅弧形**并保持站位与轴线可判断；不用无目的 360° 绕拍。
- **升降与低机位变化**：权力感增强、由弱转强、揭示高台／台阶。
- **焦点转移**：前景道具↔人物眼神、人物↔背景威胁（属于同一镜头内，不是切镜）。
- **手持**：冲突、逃跑、混乱、紧张（避免所有动作戏疯狂晃动）。

## 4. 对话、正反打与表情表演

- **对话分镜**：常用“建立双人镜 → A → B → 反应镜”，但不机械套用，也不把整段对话全写成双人镜或全写成过肩镜。记住：**重要剧情中，“听的人”有时比“说的人”更重要**（反派摊牌时切主角反应）。
- **正反打与过肩**：严格遵守 180° 轴线与视线对应（A 在左看右，B 在右看左）；过肩必须写清“从前景人物左/右肩后方拍被摄人物”（不加 `@`）。
- **关键情绪的可拍动作**：先找触发点（一句原台词、一个视线落点或剧本动作），再写镜头能读到的第一个物理反应和结束状态。避免“他很震惊／她很愤怒”等抽象情绪，改写为“手停在杯沿，眼神先避开再抬眼”“眉头收紧、下颌绷紧、右手握拳”；不说话的听者用视线、呼吸、合唇表达反应；时长偏紧时只选当前时长内做完的细节。

---

## 5. 动作、AI 可实现性与镜头衔接

- **动作与走位**：优先转头、抬眼、停顿、轻微侧身、走两步、坐下、起身、握拳、放下物品；避免单镜包含 >3 个明显动作阶段（多阶段连动如跑进→转身→拔枪→开枪，或奔跑追逐／复杂打斗，必须拆镜：`准备 → 单次攻击 → 对方反应 → 结果`）。
- **情绪戏与空镜**：情绪戏以稳定机位＋表演为核心，仅在关键转折用极慢推、微横移或焦点转移做动静对比；空镜可用于建立、时间过渡、情绪缓冲，短剧节奏下勿滥用；进入新空间时仅在观众需要理解空间关系时先给建立镜，否则可直接从人物动作切入。
- **常用衔接**：硬切（最常用）、视线切（看某处→切目标）、动作匹配切、声音先行、前景遮挡转场（适时使用，非特殊需要可简写）。

---

## 6. 分镜输出格式

默认输出简洁、可执行、无理论废话。按需写声音设计（保留原台词；环境音／拟音写大致时点方向强弱；不默认 BGM、禁音色标签）。长对白（>5 秒）切镜的 0.5 秒时间码直接写入该镜 **`运镜`（或表格 `机位／运镜`）** 字段。

### 默认紧凑卡片格式（优先）

```text
### 17-03
时长：3秒
景别：中近景
机位：人物右前方30°，平视（过肩时写“从前景人物左/右肩后方拍被摄人物”）
运镜：固定（长对白>5秒切镜时在此写明“0-3秒：甲近景；3-5.5秒：切乙反应近景…”）
画面：林默停在走廊中央，身体微侧看向画面右侧尽头，右手自然垂落。
动作：脚步停住，缓慢转头。
表情：目光从放松收紧为警觉，嘴唇微抿。
台词：林默：「谁？」（无台词可写“无”或省略）
声音：1.5s+远处木门轻响（仅本镜需交代时写）
衔接：视线切走廊尽头。
```

> 若用户明确要求表格化分镜（方便导入 Excel／飞书），可改为 Markdown 表格：`镜号｜时长｜景别｜机位／运镜｜画面与站位｜动作与表情｜台词｜声音与衔接`。
